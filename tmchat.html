Security Rules

Database Node Rules (`users/` & `chats/`):

{
  "rules": {
    "users": {
      "$uid": { ".read": "auth != null", ".write": "$uid === auth.uid" }
    },
    "friends": {
      "$uid": { ".read": "auth != null", ".write": "$uid === auth.uid" }
    },
    "chats": {
      "$chatId": { ".read": "auth != null", ".write": "auth != null" }
    }
  }
}
